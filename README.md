# 心晴 · 情绪日记与自我关怀

在线体验：https://danielpan12.github.io/mood-journal/

一本可以随时写两句的情绪日记。先记下心情和精力，再回看具体事件；试过的休息方法会留下反馈，影响下一次推荐。视觉采用纸张、墨色和少量陶土色，减少仪表盘式卡片与泛化鼓励文案。

## 已实现

- **记录**：可点击的「心情 × 精力」坐标、可轮换的具体写作问题、最近日记与七日趋势；键盘也可选择坐标。
- **日记**：五级心情、精力、细分感受、事件标签、文字与补记时间；保存后按这条记录追问一句，可选补充到原日记；编辑、删除、关键词与心情筛选、月历按日筛选。
- **发现**：7/30 天变化、分布与事件对比。将记录过某事件的日子，与未记录该事件的日子按天比较；两组各至少 3 天才展示差值。可打开每组对应的原始日记。缺失日期不补零、不连线；明确区分关联与因果。
- **休息**：1/3 分钟呼吸、3 分钟浏览器合成氛围音乐、2 分钟感官觉察、3 分钟舒展；可按可用时间筛选。计时、暂停、提前结束、真实时长、练习后感受；切后台自动暂停。
- **反馈记忆**：至少 15 秒的已保存练习计入反馈；同一方法至少试过两次且半数以上反馈「轻松一些」，才优先推荐。没有足够反馈时，使用最近心情、精力与事件。推荐原因可见，示例模式不引用个人反馈。
- **隐私与数据**：无需账号，个人数据在 localStorage；导出 JSON、校验后合并导入、删除确认、存储损坏保护、多标签同步。
- **示例体验**：首次进入展示明确标记的七日样例；个人记录与样例隔离，样例不写入、不导出。
- 手机底部导航、桌面侧栏、键盘焦点、原生模态框、减少动态效果偏好支持。

## 产品边界

本版是纯静态应用，没有登录、云端同步、后端或生成式 AI 接口。推荐是可解释规则，洞察来自记录计算。不是心理诊断或医疗服务。音乐由 Web Audio 实时合成，不使用外部音频。日记为浏览器本地明文，清理浏览器、无痕模式或更换设备可能导致记录不可见，请导出备份。

## 设计参考

- [Daylio](https://daylio.net/faq/docs/daylio-faq/about/activity-and-mood-statistics/)：低门槛记录、活动与心情关联。
- [How We Feel](https://howwefeel.org/)：命名感受、觉察情绪规律。
- [Apple Journal](https://www.apple.com/newsroom/2023/12/apple-launches-journal-app-a-new-app-for-reflecting-on-everyday-moments/)：从具体的生活瞬间开始写，减少面对空白页的压力。
- [Bearable](https://bearable.app/support/howto/how-to-find-correlations/)：对照有、无某因素的记录日，提供可回查的线索。
- [NHS 呼吸指南](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/)：舒适、轻柔、不勉强；本站短练习是体验改编。

## 源码与验证

- `app.js`：导航、页面、日记、推荐、备份管理。
- `data.js`：校验、存储、样例、统计；`data.test.mjs`：9 项数据测试。
- `patterns.js`：按天比较事件、练习反馈统计与推荐；`patterns.test.mjs`：11 项分析测试。
- `care.js`：练习计时、声音、反馈。
- `styles.css`、`editorial.css`：基础与新版响应式设计；`index.html`：入口。

无需安装依赖或构建。使用任意静态 HTTP 服务预览本目录（ES Modules 不适合直接双击 HTML）。运行测试：`node --test data.test.mjs patterns.test.mjs`。

浏览器验收已覆盖：创建/刷新/编辑/搜索/筛选/删除；导入导出、无效文件拒绝、损坏保护、示例隔离；坐标写入、保存后补记、未保存内容保护、事件对比依据、时间筛选；计时暂停、完整与提前结束、音乐启停；360/390 像素移动布局；文本注入检查。
